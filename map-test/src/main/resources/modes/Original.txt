MONSTER MAZE - MODE: ORIGINAL
==============================

Original mode is a 1:1 recreation of the original Mineplex Monster Maze source.
It receives NO gameplay QOL changes and plays exactly as the source did.

Global features that still apply to Original (quality of life / admin / safety only):
  - Pre-glass-fall jump lock: before the containment glass drops and the game
    starts, only the Jumper kit can move/jump on the spawn platform. Every other
    kit is grounded (Jump effect blocked) so nobody can get a head-start.
  - DE invisible-player dye toggle in the hotbar (slot 7): cycles the invisible
    player's visibility between lime, grey, and transparent purple.
  - Game optimisation (no functionality change).
  - Personal bests (PB): each player's best stage is saved per mode, per maze
    pattern, AND per kit. A PB line on the in-game scoreboard shows the best stage
    for the pattern being played (with the kit that achieved it). /mm pb shows all
    your bests; /mm lb shows the leaderboard; the lobby has a hologram leaderboard.

Differences from the original source:
  - None (by design). This is the reference mode all other modes are measured against.

The 'speeding' (jump-spam boost) mechanic works here exactly as in the source.

KNOWN LIMITATION - THE "BONK" (1.8 protocol-bound):
  A grounded, jump-locked (Jump -10) player who spam-presses space into a mob rarely
  gets the intended launch - they get a low "bonk" instead. This matches the source
  behaviour and is accepted as part of the game on 1.8.8: the server sends the correct
  single source impulse (verified: sentH 1.0 / sentY 0.95), but re-asserting velocity
  stacks 2-3x on 250ms+ clients, and a teleport ride removes in-air control. See the
  Modern/Speed mode notes for the full diagnosis and the modern-version (1.21+) fix path.
