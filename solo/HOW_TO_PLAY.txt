============================================
  MONSTER MAZE - SOLO
  How to play (read this first!)
============================================

You need: Minecraft Java Edition 1.8.9.

This is a single-player version of Monster Maze. You run the included
local server on your computer and play until you die. Your completed
runs are saved automatically.


--------------------------------------------
STEP 0 - Updates
--------------------------------------------
Your game checks for updates automatically every time you start it
with launcher\play.bat. If a newer version exists, it downloads the
changes before your server starts.

It does not replace your personal run records or local settings.

No internet? No problem - the game can still start without updating.
You can also run the update check manually with update.bat.


--------------------------------------------
STEP 1 - Start your server
--------------------------------------------
  Double-click:     launcher\play.bat

A black window will open. Leave it open while you play.
Wait until the server says it is ready.


--------------------------------------------
STEP 2 - Join the game
--------------------------------------------
  1. Open Minecraft (1.8.9)
  2. Click Multiplayer
  3. Click Add Server
  4. Server name:  Solo Maze
  5. Server address:  localhost
  6. Click Done, then click the server to join.


--------------------------------------------
STEP 3 - Start a run
--------------------------------------------
  In the chat, type:    /mm start

Choose your kit from the kit menu, then survive as long as you can.
Reach the next Safe Pad before the timer expires.

When you die, your run ends and your result is recorded automatically.


--------------------------------------------
MODES
--------------------------------------------

The 1.8 version has four modes:

  Original
    The original Monster Maze experience, recreated as faithfully as
    possible. Uses the original pacing and monster spawning.

  Speed
    Modern gameplay with the original timer and monster spawning.

  Modern
    Faster stages, more monsters, and expanded kit abilities.

  Lagless
    Uses a fixed monster pool instead of adding new monsters at each
    stage, with monster speed increasing as the run progresses.

If you are playing for the main leaderboard, use the mode specified by
whoever is running the competition.


--------------------------------------------
KITS
--------------------------------------------

  Jumper
    5 charged jumps in Original; 3 in the other modes. Safe Pads
    restore your charges in the enhanced modes.

  Slowballer
    Throws snowballs that slow other players. Enhanced modes also give
    you Cryo Blitz, which freezes nearby monsters.

  Body Builder
    Gain extra maximum health when you are first to a Safe Pad.
    Enhanced modes also give you Body Rush to deflect monster hits.

  Repulsor
    Launch nearby monsters away from you. You have 3 charges.

  Maverick
    In enhanced modes, monster hits launch you toward the next Safe Pad.


--------------------------------------------
STEP 4 - Submit your score
--------------------------------------------
Your run is saved automatically in the server's solo-runs folder.

If your copy is configured for Discord submissions, run:

  submitter\submit.bat

This posts every saved run that has not already been submitted. A run
is only moved to the submitted folder after the post succeeds, so a
network failure does not discard it.

If no submission webhook is configured, your run remains safely stored
locally and can be submitted later.


--------------------------------------------
STEP 5 - Stop
--------------------------------------------
  Double-click:     launcher\stop.bat

You can also close the black server window when you are finished.


--------------------------------------------
TROUBLESHOOTING
--------------------------------------------
Q: "Double-clicking play.bat does nothing / it closes instantly"
   Make sure the included Java runtime is present. If it is missing,
   ask whoever provided the package for help.

Q: The server is still starting
   Give it a little time, especially on the first start while maps are
   being prepared.

Q: My score was not posted to Discord
   Make sure the submission webhook has been configured, then run
   submitter\submit.bat again. If there is no webhook configured, the
   run will remain in the local solo-runs folder.

Q: play.bat or update.bat says the server is already running
   Stop the server with launcher\stop.bat, then try again.

Q: The updater cannot connect
   Check your internet connection. Updates are optional and the game
   can still start without them.

That's it. Have fun!
